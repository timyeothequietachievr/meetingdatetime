# Meeting Date Time

Cross-timezone meeting planner from The Quiet Achiever.

- **Site:** [meetingdatetime.thequietachievr.com](https://meetingdatetime.thequietachievr.com)
- **Design system:** Quiet Achiever tokens (Literata, Basier Circle, paper / ember / ink)

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js · Tailwind CSS v4 · Vercel
